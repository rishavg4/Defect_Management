# Defect Management Dashboard

Interactive, enterprise-grade Defect Management & Tracking Dashboard for monitoring defect lifecycles, SLA compliance, severity breakdowns, squad assignments, and root cause analysis.

---

## ?? Features

- **Executive Defect KPIs**: Total Defects, Open, In Progress, Ready for Retest, Closed, Reopened, and P1/P2 critical counts.
- **Visual Analytics**:
  - Defect distribution by status and priority (P1–P4).
  - Trend line charts tracking defect opening vs. closure rates.
  - Team/squad workload and resource allocation breakdowns.
  - Root Cause Analysis (RCA) insights and Pareto charts.
- **Defect Drill-down & Modals**: Comprehensive defect detail view with linked test case IDs, triage comments, and lifecycle timestamps.
- **Client-Side & Secure**: Zero server dependencies — runs completely in-browser with zero data leakage.
